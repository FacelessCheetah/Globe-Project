### For this project I used CsvHelper to  get data from a csv file in unity:
* [CsvHelper](https://joshclose.github.io/CsvHelper/)
* [CsvHelper-For-Unity](https://github.com/bilal-arikan/CsvHelper-For-Unity)

### Data used for this project: 
* [co-emissions-across-countries-regions-and-sectors](https://www.kaggle.com/datasets/shreyanshdangi/co-emissions-across-countries-regions-and-sectors/data)

### globe model used: 
* [Earth Rendering Free.](https://assetstore.unity.com/packages/vfx/shaders/earth-rendering-free-54914)
* This package came with controls to rotate the camera and move the globe. I did add some conditions where the rotation stopped
